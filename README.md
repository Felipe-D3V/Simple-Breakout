Mais um projeto desenvolvido em C# usando a Unity Engine.
Durante esse jogo, aprimorei várias habilidades essenciais em programação e no desenvolvimento de jogos. Hoje, conceitos como instâncias, corrotinas, paletas de gradiente, UI dinâmica e gestão de cenas se tornaram parte natural do meu fluxo de trabalho.

Este é um projeto de estudo e evolução pessoal, inspirado no clássico Breakout, mas com algumas ideias próprias.

🚀 Recursos e Funcionalidades
🎮 Gameplay

Mecânicas clássicas de Breakout

Bola, plataforma e blocos com comportamentos próprios

Blocos com diferentes tipos e resistência

🧱 Level Generator

Sistema de geração de fases que cria blocos automaticamente

Geração baseada em área específica configurável via Inspector

Permite criar layouts variados sem necessidade de montar tudo manualmente

📊 Ranking Local

Sistema de pontuação que salva os melhores resultados

Armazena scores localmente

Interface simples para visualizar o ranking diretamente no jogo

🧩 UI Simples e Funcional

Menu inicial

Contagem regressiva

Game Over e tela de vitória

Sistema de navegação básico

🔄 Corrotinas

Usadas para animações temporizadas, delays, contagem regressiva e lógica de fluxo

Aprendi melhor sobre o ciclo de vida das corrotinas e sua utilização estratégica

🎨 Gradientes e Variedade Visual

Gradientes aplicados nos blocos usando Unity Gradient

Paletas diferentes para estágios do jogo

🛠️ Tecnologias Utilizadas

Unity Engine (versão que você usa — opcional colocar)

C#

Unity UI

Corrotinas

PlayerPrefs (ou sistema customizado, se for o caso)

Unity Animator (se usar animações na UI)
